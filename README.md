# Instructor Motion Training — 2.0

منصة تدريب رياضي متعددة الرياضات — الإصدار الثاني (React).
المالك: Instructor: Mohamed Ayad — مشرف التربية البدنية.

- الإصدار الحالي المستقر (v28): https://instructorforever2000.github.io/instructor-motion/
- هذا المستودع: إعادة بناء على مراحل، قسمًا قسمًا، بموافقة المالك.

## البنية
- `src/app` — هيكل التطبيق والتنقل
- `src/features/<قسم>` — كل قسم مستقل بملفاته
- `src/components/ui` — مكونات التصميم المشتركة (shadcn)
- `src/lib` — أدوات مشتركة

## التقنية
React + Vite + TypeScript + Tailwind + shadcn — النشر تلقائي على GitHub Pages عند كل رفع لفرع main.
